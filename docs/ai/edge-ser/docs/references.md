# Tài liệu tham khảo

1. S. R. Livingstone và F. A. Russo, “The Ryerson Audio-Visual Database of
   Emotional Speech and Song (RAVDESS): A dynamic, multimodal set of facial and
   vocal expressions in North American English,” *PLOS ONE*, 13(5), e0196391,
   2018. https://doi.org/10.1371/journal.pone.0196391
2. `prasenjit52282/embedded-audio-emotion`, repository mã nguồn dùng emlearn
   để export Random Forest thành C header. https://github.com/prasenjit52282/embedded-audio-emotion

RAVDESS là dataset và taxonomy nhãn dùng để train model trong dự án. Repository
tham khảo chỉ được dùng cho script export `em_model.py`; dữ liệu của repo này
không được dùng.
